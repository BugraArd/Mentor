# MENTOR — web

Next.js 16 uygulaması. Genel proje dokümantasyonu ve kurulum adımları için bkz.
[`../README.md`](../README.md).

## Geliştirme

```bash
npm install
npm run dev
```

http://localhost:3000

## Next.js 16 uyarısı

Bu sürüm önceki Next.js sürümlerinden farklı davranıyor olabilir (örn. `middleware.ts`
yerine `src/proxy.ts`, `cookies()`/`params` async-only). Kod yazmadan önce
`node_modules/next/dist/docs/` içindeki ilgili kılavuzu oku — bkz. `AGENTS.md`.
